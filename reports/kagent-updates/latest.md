## Highlights

- **Substrate: the egress credential cache no longer outlives the grant** ([substrate#170](https://github.com/kagent-dev/substrate/pull/170), codyhartsook, merged 11-13 20:04). The gateway cached each fetched credential 5 min and a hit never re-consulted the provider — so a token issued only while the actor handles that user's request kept working up to 5 min after the request ended, and a revoked grant lagged identically. New `atenetEgress.extraCredentialProviders[].cacheTtl` (unset = 5m as before; `0s` = every call hits the provider); unknown keys or a bad duration now fail at render instead of being dropped and silently leaving the 5m cache on. This is the knob for short-lived/Vault-issued credentials on omni-viper; it needs the agentgateway `cacheTtl` support in the pinned v1.7.0 image.
- **Substrate: no OTLP push to a collector you never set** ([substrate#166](https://github.com/kagent-dev/substrate/pull/166), pennycoders, merged 11-13 22:45, fixes substrate#76). At default values ate-api-server, atelet, ate-controller and k8s-credential-provider pushed to the SDK default `localhost:4317` and logged a connection error ~once a minute. An enabled signal with no endpoint now renders `OTEL_<SIGNAL>_EXPORTER` as disabled; metrics get `prometheus` not `none`, so scraped endpoints survive (`none` would close atecontroller's `:8080`). k8s-credential-provider finally gains `substrate.otel.env`, so it can be configured at all.
- **kagent UI: clone an agent in one click** ([kagent#3661](https://github.com/kagent-dev/kagent/pull/3661), toreysoloio, merged 11-13 19:30). Agents / Agent templates / Harnesses rows get a `⋯` menu — Edit (Open on templates), "Create new … from this" (prefilled, `-copy` name), Delete; a bad `?from=` URL gives a blank form plus an alert instead of a hang. Good for building demo variants live instead of editing manifests — and re-screenshot the list views. Same-day [kagent#3672](https://github.com/kagent-dev/kagent/pull/3672) fixes the flaky harnesses Playwright delete step (test-only).
- **Still the two things to know from yesterday:** [tools#107](https://github.com/kagent-dev/tools/pull/107) (passthrough token via per-call `0600` kubeconfig, never argv) and [kagent#3399](https://github.com/kagent-dev/kagent/pull/3399) (opt-in crash recovery on send). Docs theme moved to released `v0.5.0` ([website#725](https://github.com/kagent-dev/website/pull/725)).
