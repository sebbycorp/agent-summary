## Highlights

- **The one that matters for omni-viper — substrate [#192](https://github.com/kagent-dev/substrate/pull/192)** (PetrMc, opened 11-22, +20/−3, `blocked`): atelet falls back to hard-coded `api.ate-system.svc`, so **installing Agent Substrate under any other release name or namespace means workers never register**. Both atelet templates now pass `--ateapi-address` and `--ateapi-server-name` the way ate-controller gets `--ateapi-conn-spec`; canonical render unchanged. Related to #31. If your omni-viper substrate release isn't `ate-system`, this is the fix — and it's unreleased, so today you patch the value or keep the default namespace.
- **kagent [#3765](https://github.com/kagent-dev/kagent/pull/3765)** (`bug`, xixi-box, +29/−26) — telemetry was exported *after* `SettleTask`, and since settlement can publish the task and start actor suspension before the RPC returns, the checkpoint cut the export with EOF: **last-turn traces silently vanished**. Fix keeps the bounded flush before settlement, drops the deferred one. Fixes #3758. Matters whenever you demo OTel traces on Substrate actors.
- **EgressPolicy goes multi-auth — [#3762](https://github.com/kagent-dev/kagent/pull/3762)** (`enhancement`, spirilis, +260/−40, 8 files): adds an `authentications` **array** per destination, mutually exclusive with `authentication` (CEL-enforced), `authentication` documented as deprecated. **No UI support yet.** On merge your EgressPolicy YAML migrates; implements #3714.
- **RemoteMCPServer validation hole — [#3763](https://github.com/kagent-dev/kagent/pull/3763)** (`bug`): the CEL rejected `spec.tls` only on a lowercase `http://`, so `HTTP://` / `Http://` were admitted with TLS set while traffic went plaintext. Fix lowercases the scheme check and **regenerates the shipped CRD** — re-apply manifests. Fixes #3757.
- **Multi-MCP tool collisions — [#3764](https://github.com/kagent-dev/kagent/pull/3764)** (`bug`, wendaining): disambiguates tools from multiple MCP servers; hits any agent behind several `RemoteMCPServer`s.
- **doc2vec [#149](https://github.com/kagent-dev/doc2vec/pull/149) left draft** (720/−75, updated 11-23 13:16Z): Zendesk kills API tokens — none issued after 2026-10-27, all deactivated **2027-04-30** — so sources gain OAuth `client_credentials` and ticket sync moves from the Search API to the incremental cursor export. `email`+`api_token` still work with a deprecation warning. RAG demos on Zendesk content need this before the deadline.
- **Only security-labelled PR org-wide:** doc2vec [#150](https://github.com/kagent-dev/doc2vec/pull/150) (Snyk, peterj, opened 11-23) upgrades jsdom 26.0.0 → 27.0.1.
