## Highlights

- **Security, merged: caller tokens no longer leak through kubectl argv** ([tools#107](https://github.com/kagent-dev/tools/pull/107), braghettos, merged 11-13 09:33 by dimetron). Under `TOKEN_PASSTHROUGH=true` the k8s tools passed the bearer token as `--token <token>`; on failure the joined argv became the `ToolError.Operation` → tool result → agent context, model requests, session history, span status, the process list, and a logged cache key. Worse, `--token` does not override a kubeconfig **client certificate**, so the API server could authenticate as the *server's* identity — passthrough did not constrain the caller. Fix: per-call `0600` `tokenFile` kubeconfig in a `0700` temp dir, cluster stanza copied verbatim, no impersonation/exec/auth-provider inherited, plus `redact.Args`/`redact.String` on logs, spans and errors. Behaviour change worth demo-checking: `k8s_get_cluster_configuration` now shows one cluster and user `kagent-token-passthrough`, not the server's kubeconfig.
- **Crash recovery is now opt-in and real** ([kagent#3399](https://github.com/kagent-dev/kagent/pull/3399), adalundhe, merged 11-13). `config.sessions.automaticRecovery: true` (default `false`, chart mentions it only in a comment so default installs render unchanged) admits recovery for crashed runtimes on A2A send, recovers a send refused for an open turn, recovers a send blocked by a lost-worker suspension, and reverts proven-unaccepted sends; a send waits 10 s, then answers `KAGENT_SEND_NOT_ACCEPTED` / `state: RECOVERING` for the client to retry. Chat adds a **Recover** button (`RevertSession`) on window expiry, `KAGENT_TURN_ACTIVE`, and pending recovery. Missing runtimes are recorded FAILED/NONE with reason `RuntimeLost` — that persistence part applies regardless of the flag. This is the answer to the omni-viper "stuck session after a substrate worker dies" demo failure mode.
- **CRD/API change: kagent-owned typed references** ([kagent#3604](https://github.com/kagent-dev/kagent/pull/3604), codyhartsook, merged 11-12, 57 files). Model and MCP-server references take optional `group` + `kind` (like v1alpha2's `TypedReference`) instead of `corev1.TypedObjectReference` / kindless `ObjectReference`; unknown kinds report `InvalidKind` on `ResolvedRefs`, Gateway-API style; MCP `kind` defaults to `RemoteMCPServer` in-schema; `apiGroup` is deprecated-and-must-be-omitted (v1.0.x clients send `null`, and gRPC rejects unknown fields). Go breaking: `ObjectReference` → `ModelConfigReference`, `MCPToolBinding.Server` retyped. **Rollback caveat for alpha12 testing:** a v1.0.x controller ignores `group`/`kind` and silently resolves the same-named `ModelConfig` (potentially a different credential) — point model refs back to `ModelConfig` before rolling back. A second reference kind must ship at least one release later. UI side-car [#3607](https://github.com/kagent-dev/kagent/pull/3607) keeps group/kind on references the UI saves.
- **Sandbox image scans stop failing noisily:** `sandbox-guest` only ran `apk add`, so it shipped base Alpine versions — now `apk upgrade --no-cache` first, matching the Claude/Codex harness images ([#3664](https://github.com/kagent-dev/kagent/pull/3664)). Rebuild the guest image to clear those findings on omni-viper.
- **Recovery observability landed** ([#3593](https://github.com/kagent-dev/kagent/pull/3593), merged 11-12): session and push-recovery activity is now exposed in telemetry — pair it with #3399 when demonstrating crash recovery.
- **UI refresh (re-screenshot the deck):** all create buttons collapsed into one Create modal ([#3633](https://github.com/kagent-dev/kagent/pull/3633)), agent templates now count tools rather than bindings ([#3660](https://github.com/kagent-dev/kagent/pull/3660)), and permission-denied reads render one way ([#3551](https://github.com/kagent-dev/kagent/pull/3551)).
- **Docs/architecture aids:** agent-creation diagram with a CI render check ([#3575](https://github.com/kagent-dev/kagent/pull/3575)) and agent-send-message diagram ([#3609](https://github.com/kagent-dev/kagent/pull/3609)); docs theme bumped to `docs-theme-extras` v0.5.0 ([website#724](https://github.com/kagent-dev/website/pull/724)).
