## Highlights

- **`TOKEN_PASSTHROUGH` was only half-true — now a PR fixes it (tools [#114](https://github.com/kagent-dev/tools/pull/114), braghettos, opened 11-16).** Today only `pkg/k8s` kubectl tools send the caller's bearer token; `helm`, `istioctl`, `cilium` and `kubectl argo rollouts` run with the *server's* kubeconfig — so either every helm call dies with `the server has asked for the client to provide credentials` (author saw 7/7 in 30h vs 70/70 kubectl calls), or those tools silently act as the **server** identity, which is exactly what passthrough exists to prevent. Fix: one resolver `internal/mcp/passthrough.go` feeding `CommandBuilder.WithToken` via the per-call kubeconfig from #107 — token never on argv/logs, and tokenless cluster calls are **refused**. Demo impact: don't claim "agent's own identity end-to-end" on `tools:v0.3.1`; the tokenless-call refusal is a behaviour change that needs a release note. `kubescape` is still uncovered.
- **Tools chart can't read kagent's own CRDs (tools [#113](https://github.com/kagent-dev/tools/pull/113), dimetron, 11-16).** With `rbac.readOnly: true`, `k8s_get_resources` cannot read Agents/ModelConfigs — adds `get/list/watch` on `api.kagent.dev` v1alpha3 (agents, agenttemplates, egresspolicies, harnesses, modelconfigs, modelproviderconfigs, remotemcpservers, sandboxtemplates), matching the kagent chart's reconcile role. Directly relevant to the "agent inspects its own platform" demo.
- **Namespace-scoped install fix landed (kagent [#3671](https://github.com/kagent-dev/kagent/pull/3671), shashankram, merged 11-16, commit [`d79fea0`](https://github.com/kagent-dev/kagent/commit/d79fea08a7ee65bdd37236c43169635502d01772)).** With `controller.metrics.enabled=true` and `config.metrics.secure=false` the chart created an unused `metrics-reader` ClusterRole that blocked install by namespace-scoped accounts; it now renders only for secure metrics, with HTTP metrics covered by `rbac.namespaces`/`global.watchNamespaces`. Good for tenant-scoped demo installs — **untagged** (post-v1.0.1 main).
- **Big API/CRD proposal: declarative graph workflows (kagent [#3673](https://github.com/kagent-dev/kagent/pull/3673), dimetron, 131 files / +14,579, updated 11-16).** YAML `AgentSystem` (`adk.declarative/v0.2`) → ADK Go 2.x graphs: cel/tool/llm/agent/join/workflow/parallel_worker/dynamic/hitl nodes, routed edges with fan-out/fan-in, CEL guardrails (`before/after_model|tool`), remote MCP servers, ConfigMap prompts, subagent `isolation: Shared|Isolated`, 22 Go-vs-YAML parity patterns. Wired in via `AgentTemplate.spec.workflowFrom` (mutually exclusive with `systemPrompt`), **BYO harness only** — the kagent harness rejects `workflow` for now. Strong "no-code workflow agent" demo candidate, but it's a blocked open PR, not main.
- **Auth nit worth testing on the trusted gateway path:** kagent [#3687](https://github.com/kagent-dev/kagent/pull/3687) — accept the `Bearer` scheme case-insensitively in trusted-proxy mode (some clients send `bearer`).
- **Docs-bots keep leaking the roadmap.** 11 automated drafts from 11-15 remain unmerged (Anthropic self-hosted sandboxes [#736](https://github.com/kagent-dev/website/pull/736), `azureAdToken` removal [#731](https://github.com/kagent-dev/website/pull/731), lazy MCP discovery [#732](https://github.com/kagent-dev/website/pull/732), `user.id` telemetry [#727](https://github.com/kagent-dev/website/pull/727)); new today: website [#738](https://github.com/kagent-dev/website/pull/738) fixes broken links from checker report #737.
