## Highlights

- **kagent ships an example agent out of the box ([#3554](https://github.com/kagent-dev/kagent/pull/3554), danielle-mustillo, 11-16, `enhancement`).** `platform-agent` installs on `kagent-default` and routes Kubernetes/Helm/Istio questions to specialist AgentTemplates; on by default with `kagent install` (`examples.platformAgent.enabled`; skipped by `--profile minimal`; the chart now *fails to render* if enabled without `kagent-default` or kagent-tools). Built-in skills come from **kagent-tools 0.3.1 pinned by digest** in `files/builtin-skills.json` (render fails on a tools-version mismatch) — no separate skills image; the agent-template form gains a skills picker (built-in / OCI / Git / S3). Author's caveats: Git+S3 skills need #3435, `--reuse-values` upgrades render no examples, and platform-agent loaded its skill in only **2 of 4 chats**.
- **UI image CVEs fixed — untagged ([#3693](https://github.com/kagent-dev/kagent/pull/3693), Charlesthebird, 11-16, `bug`).** nginx base digest for glibc **CVE-2026-84243** (medium), `golang:1.27.3-alpine` → `1.27.4-alpine` entrypoint for Go stdlib **CVE-2026-97054**, plus `eslint ^10.15.0` + `minimatch ^11.0.1` for dev-only GHSA-g3hv-75wg-m249; trivy/grype clean per the PR. If your scanner flags the UI image on omni-viper, the fix is post-v1.0.1 main.
- **tools toolchain jump ([#104](https://github.com/kagent-dev/tools/pull/104), dimetron, 11-17, [`b8c6431`](https://github.com/kagent-dev/tools/commit/b8c6431e6dc0fe56cef52a475165bad80d4f1cdd)).** Go 1.27.3 → **1.27.4**; bundled CLIs **Istio 1.31.3 → 1.32.0**, Argo Rollouts 1.10.1 → 1.10.2, kind node 1.34.0 → 1.37.0, CI Helm 4.1.1 → 4.3.1. Changes which `istioctl`/`argo`/`helm` the agent actually drives — re-test CLI demos on a build containing it (v0.3.1 is 13 days stale).
- **Security, still open:** [#114](https://github.com/kagent-dev/tools/pull/114) (`TOKEN_PASSTHROUGH` reaches only kubectl; helm/istioctl/argo/cilium run as the *server*) hasn't moved since 11-16 — keep the caveat on any "agent's own identity end-to-end" claim on `tools:v0.3.1`. New: [#116](https://github.com/kagent-dev/tools/pull/116) bumps indirect `cilium` → 1.19.5 / `ebpf` → 0.22.0 for **four advisories** (CVE-2026-56742 cross-namespace HTTPRoute redirect, CVE-2026-56743 NetworkPolicy `ipBlock`, CVE-2026-53935 CiliumLocalRedirectPolicy hijack, CVE-2026-10722 ebpf BTF overflow) via kubescape → k8s-interface; author's `govulncheck` 6 → 3 symbol findings.
- **System prompt leaked onto the A2A agent card ([#3704](https://github.com/kagent-dev/kagent/pull/3704), moezdil, 11-16, `bug`, blocked).** Stops the ADK replacing the pod agent card's own skills with ADK-built ones that copy the agent instructions (fixes #2549) — cherry-pick before any A2A demo where the card is reachable.
- **UI polish for live demos ([#3644](https://github.com/kagent-dev/kagent/pull/3644), cjlg-soloio, 11-16, `bug`).** MCP tools sorted alphabetically, "Agent template" vs "Harness" split into separate explained rows in the chat side panel, "Back to conversation" from an AgentTemplate opened out of a chat.
- **New opens:** kagent [#3702](https://github.com/kagent-dev/kagent/pull/3702) (Ollama options sent with wrong types), [#3706](https://github.com/kagent-dev/kagent/pull/3706) (non-streaming Anthropic with large `max_tokens`), [#3679](https://github.com/kagent-dev/kagent/pull/3679)/[#3680](https://github.com/kagent-dev/kagent/pull/3680) (`kagent harness|model|tool list`, `agent delete`, `kagent skill install`), tools [#117](https://github.com/kagent-dev/tools/pull/117) (LLM-backed tools registered only when configured).
