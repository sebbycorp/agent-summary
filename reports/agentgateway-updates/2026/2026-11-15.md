## Highlights

- **LiteLLM migration is being built out in earnest** — three stacked PRs from the same author on 11-14 against issue #2607: [4413](https://github.com/agentgateway/agentgateway/pull/4413) maps inbound API-key settings, [4414](https://github.com/agentgateway/agentgateway/pull/4414) covers retry/timeout/order/pass-through/guardrails/MCP (109 files, +4,645), [4415](https://github.com/agentgateway/agentgateway/pull/4415) covers DB-managed keys, budgets and MCP grants. **Demo impact:** the "migrate off LiteLLM" story goes from diagnostics-only (yesterday's #3663) to actual conversion — worth re-running an import before quoting feature parity.
- **Two models with the same name on one listener is about to become a config error** — [4419](https://github.com/agentgateway/agentgateway/pull/4419), opened today. Today both silently coexist and either can answer; the fix picks one (oldest creation time, then namespace/name) and marks the loser `Accepted=False, Conflicted`. **Demo impact:** shadow-traffic or canary setups where two models share a name currently answer unpredictably — good caveat slide, and the fix is not merged yet.
- **Vertex + Anthropic beta flags fixed (open)** — [4416](https://github.com/agentgateway/agentgateway/pull/4416): Vertex rejects requests carrying unsupported `anthropic-beta` values; the PR keeps only allowed values, with `AGENTGATEWAY_VERTEX_ANTHROPIC_BETA_HEADERS` as an override. Fixes #4396. Relevant if you demo Claude-via-Vertex with prompt caching or thinking beta headers.
- **Windsurf/Devin Desktop recipe corrected (open)** — [4417](https://github.com/agentgateway/agentgateway/pull/4417): the old recipe set `Http: Proxy` to the LLM gateway URL, so `CONNECT` returned 405 and Devin Desktop lost network entirely. New path runs Claude Agent over ACP with per-agent env vars pointed at agentgateway. Author notes Windsurf is effectively EOL. Fixes a broken tool-integration demo.
- **1.8 release notes are being assembled** — website [1519](https://github.com/agentgateway/website/pull/1519) "Release notes from the PR tracker" is open and updated today, alongside automated draft-docs PRs for the guardrail/Helm/LLM-pricing merges ([1542](https://github.com/agentgateway/website/pull/1542)–[1545](https://github.com/agentgateway/website/pull/1545)) and reference-docs regens [1526](https://github.com/agentgateway/website/pull/1526) / [1527](https://github.com/agentgateway/website/pull/1527). Signal that a cut is nearer than the Oct cadence suggested.
- **Only merge in window is CI hygiene** — [4373](https://github.com/agentgateway/agentgateway/pull/4373) makes the `cel-derive` expand test build its own fixtures; no behavioural change, no re-test needed.
